# DX601 Week 4 — Confidence Intervals and Statistical Testing

## Big Picture

Week 4 is about using sample data to make justified decisions under uncertainty.

The two main tools are:

- **Hypothesis testing** → decide whether the data gives enough evidence to reject a claim.
- **Confidence intervals** → give a range of plausible values for an unknown population parameter.

---

## 1. Hypothesis Testing

### Null hypothesis \(H_0\)

The **null hypothesis** represents the default/status-quo assumption.

Hypothesis testing asks whether the observed data would be unusually unlikely if \(H_0\) were true.

The final decision is:

- **Reject \(H_0\)**
- **Fail to reject \(H_0\)**

Do **not** interpret "fail to reject" as proving that \(H_0\) is true.

---

## 2. Type I and Type II Errors

| Reality / Decision | Fail to Reject \(H_0\) | Reject \(H_0\) |
|---|---|---|
| \(H_0\) is true | True Negative (TN) | False Positive (FP) |
| \(H_0\) is false | False Negative (FN) | True Positive (TP) |

Important notation:

\[
Pr[FP] = \alpha
\]

\[
Pr[FN] = \beta
\]

Therefore:

\[
Pr[TN] = 1-\alpha
\]

\[
Pr[TP] = 1-\beta
\]

- **Type I error** = False Positive
- **Type II error** = False Negative
- Confidence level is commonly written as:

\[
1-\alpha
\]

So a smaller \(\alpha\) means a higher confidence level.

---

## 3. \(p\)-Values

A **\(p\)-value** measures how extreme the observed test statistic is under the assumption that \(H_0\) is true.

Decision rule:

\[
p < \alpha \quad \Rightarrow \quad \text{reject } H_0
\]

### One-tailed tests

Use when direction matters.

Example:

> Is model \(A\) better than model \(B\)?

Right-tailed:

\[
p = Pr[X \ge x \mid H_0]
\]

Left-tailed:

\[
p = Pr[X \le x \mid H_0]
\]

### Two-tailed tests

Use when you only care whether something is **different**, not which direction.

Example:

> Do model \(A\) and model \(B\) perform differently?

General form:

\[
p = 2\min\{Pr[X\ge x\mid H_0],Pr[X\le x\mid H_0]\}
\]

For a symmetric distribution about 0:

\[
p = Pr[|X|\ge|x|\mid H_0]
\]

---

## 4. \(z\)-Scores

Use \(z\)-scores when the test statistic is modeled by a normal distribution and standardized to mean 0 and variance 1.

For a sample value \(x^{(i)}\):

\[
z^{(i)} = \frac{x^{(i)}-\mu}{\sigma}
\]

Interpretation:

- \(z=0\) → at the mean
- Large positive or negative \(|z|\) → more unusual
- Farther from 0 → more evidence against \(H_0\)

A \(z\)-test is essentially a specialized \(p\)-value test for a normal distribution.

---

## 5. Student's \(t\)-Test

Use a Student's \(t\)-test when testing means and the population standard deviation is unknown.

The course uses:

\[
t = \frac{\hat{\mu}-\mu}{\hat{\sigma}/\sqrt{N}}
\]

where:

- \(\hat{\mu}\) = sample mean
- \(\mu\) = assumed mean under the null hypothesis
- \(\hat{\sigma}\) = sample standard deviation
- \(N\) = number of samples

Degrees of freedom:

\[
df=N-1
\]

The Student's \(t\) distribution is similar to the normal distribution but has **heavier tails**, reflecting extra uncertainty from estimating the population standard deviation.

### One-sided vs. two-sided \(t\)-tests

- **Two-sided** → "Are the means different?"
- **One-sided** → "Is one mean greater/better than the other?"

---

## 6. Comparing Two Models Using Cross-Validation

If models \(A\) and \(B\) are evaluated on the same folds, compare their paired fold results.

For each fold:

\[
\delta = A-B
\]

Then test whether the average difference is 0.

Null hypothesis:

\[
H_0:\mu_\delta=0
\]

If the resulting \(t\)-value is sufficiently extreme, reject \(H_0\).

This lets you justify whether the models are statistically different rather than just looking at their raw average accuracies.

---

## 7. Multiple Hypothesis Testing

Repeatedly testing many hypotheses increases the chance of getting false discoveries by random chance.

Main idea:

> The more hypotheses you test, the more careful you must be about your significance level \(\alpha\).

A common strategy is to make \(\alpha\) stricter as the number of tests increases.

---

## 8. Permutation Tests

Permutation tests compare two groups without requiring a strong parametric model.

Basic idea:

1. Start with groups \(A\) and \(B\).
2. Define a statistic, such as the difference in group means.
3. Under \(H_0\), assume labels and measurements are independent.
4. Randomly shuffle the labels many times.
5. Recalculate the statistic after each shuffle.
6. Compare the real statistic against the shuffled/null distribution.

If the real statistic is very extreme relative to the shuffled distribution, that is evidence against \(H_0\).

---

# Confidence Intervals

## 9. What a Confidence Interval Means

A confidence interval gives a range of plausible values for an unknown population parameter.

General form:

\[
[L(X),U(X)]
\]

with:

\[
Pr[L(X)\le\theta\le U(X)] = 1-\alpha
\]

The population parameter \(\theta\) is treated as fixed; the interval changes from sample to sample.

Correct interpretation of a 97% confidence interval:

> If we repeatedly sampled and constructed intervals using the same method, about 97% of those intervals would contain the true population parameter.

Do **not** interpret it as:

> "There is a 97% probability that the fixed parameter is inside this particular already-computed interval."

---

## 10. Confidence Interval Structure

Many confidence intervals have the form:

\[
\hat{\theta}\pm\epsilon(X)
\]

where:

- \(\hat{\theta}\) = point estimate
- \(\epsilon(X)\) = margin of error

Larger samples usually produce narrower confidence intervals.

---

## 11. Mean with Known Population Variance

If population standard deviation \(\sigma\) is known:

\[
SE(\bar{X})=\frac{\sigma}{\sqrt{N}}
\]

The confidence interval for the population mean is:

\[
\bar{x}\pm z_{1-\alpha/2}\frac{\sigma}{\sqrt{N}}
\]

For a 95% confidence interval:

\[
z_{0.975}\approx1.96
\]

so:

\[
\bar{x}\pm1.96\frac{\sigma}{\sqrt{N}}
\]

---

## 12. Mean with Unknown Population Variance

Usually \(\sigma\) is unknown, so use the sample standard deviation \(s\) and the Student's \(t\) distribution.

\[
T=\frac{\bar{X}-\mu}{S/\sqrt{N}}
\]

with:

\[
df=N-1
\]

The confidence interval is:

\[
\bar{x}\pm t_{1-\alpha/2,N-1}\frac{s}{\sqrt{N}}
\]

Use **\(t\)** instead of **\(z\)** because estimating \(\sigma\) introduces additional uncertainty.

---

## 13. Confidence Intervals vs. Hypothesis Tests

They are closely related.

For a two-sided test at significance level \(\alpha\):

- If the hypothesized value lies **outside** the corresponding \(100(1-\alpha)\%\) confidence interval → reject it.
- If it lies **inside** the interval → fail to reject it.

Difference in emphasis:

- **Hypothesis test:** Is this particular value inconsistent with the data?
- **Confidence interval:** What range of values is reasonably compatible with the data?

---

## 14. Choosing a Statistical Test

General rule:

> Use the **most specialized test whose assumptions your data satisfies**.

Rough hierarchy discussed in the lesson:

\[
p\text{-value testing} \rightarrow z\text{-testing} \rightarrow t\text{-testing}
\]

More specialized tests can provide better guarantees, but only when their assumptions are justified.

If assumptions such as approximate normality are not reasonable, use a different method such as a nonparametric test.

---

# Quick Memory

- \(H_0\) = default/status quo.
- Reject \(H_0\) only when the data gives enough evidence.
- Type I error = false positive = \(\alpha\).
- Type II error = false negative = \(\beta\).
- Confidence level = \(1-\alpha\).
- \(p<\alpha\) → reject \(H_0\).
- One-tailed = direction matters.
- Two-tailed = any difference matters.
- \(z\)-score = distance from the mean in standard deviations.
- \(t\)-test = mean testing when population variance is unknown.
- \(df=N-1\).
- Confidence interval = plausible range for a population parameter.
- Known \(\sigma\) → use \(z\).
- Unknown \(\sigma\) → use \(t\).
- Larger \(N\) → smaller standard error → narrower confidence interval.
- When comparing model results across the same folds, test the paired differences.

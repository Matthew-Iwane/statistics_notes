# 2. Randomness

**Randomness** means:

> We know the possible outcomes, but we do not know which outcome will occur before the experiment happens.

Example: flip a fair coin.

Possible results:

- Heads
- Tails

We know the possibilities, but not the result ahead of time.

---

# 3. Random Experiment

A **random experiment** is one execution of a random process.

Examples:

- flip a coin once
- roll a die once
- measure the next customer's wait time
- randomly select a page from a book
- generate a random graph

The result is uncertain before the experiment happens.

---

# 4. Sample Space — `\Omega`

The **sample space** is the set of every possible outcome.

The course uses:

```math
\Omega
```

Example: one coin flip

```math
\Omega = \{H,T\}
```

Example: six-sided die

```math
\Omega = \{1,2,3,4,5,6\}
```

Example: two coin flips

```math
\Omega = \{HH,HT,TH,TT\}
```

### Memory

> Sample space = everything that could possibly happen.

---

# 5. Outcome

An **outcome** is the actual result produced by one random experiment.

If:

```math
\Omega = \{1,2,3,4,5,6\}
```

and the die lands on:

```math
4
```

then `4` is the outcome.

### Important distinction

```text
Sample space = all possible results
Outcome      = the one result that actually happened
```

---

# 6. Random Process

A **random process** is a process where:

1. there is a sample space
2. the result belongs to that sample space
3. we do not know beforehand which member of the sample space will be returned

Conceptually:

```text
random_process()
       ↓
one unknown member of Ω
```

Example:

```text
roll_die()
    ↓
4
```

Before the function runs:

```math
\Omega = \{1,2,3,4,5,6\}
```

Afterward, one outcome is observed.

---

# 7. Event

An **event** is a set of outcomes from the sample space that we care about.

Formally:

```math
E \subseteq \Omega
```

Example:

```math
\Omega = \{1,2,3,4,5,6\}
```

Define the event:

> Roll an even number.

Then:

```math
E = \{2,4,6\}
```

If the outcome is `4`, the event occurred.

If the outcome is `5`, it did not occur.

### Memory

> An event is basically a yes/no question: did the observed outcome belong to this set?

---

# 8. Outcome vs. Event

Example:

```math
\Omega = \{1,2,3,4,5,6\}
```

Outcome:

```math
4
```

Event:

```math
E = \{2,4,6\}
```

Because:

```math
4 \in E
```

the event occurred.

```text
Outcome = one result
Event   = a set or condition describing results
```

---

# 9. Probability

Probability describes how likely an event is.

```math
0 \leq Pr[E] \leq 1
```

Meaning:

- `0` = impossible
- `1` = guaranteed
- `0.5` = 50% chance

For a fair coin:

```math
Pr[H] = 0.5
```

```math
Pr[T] = 0.5
```

The total probability across all possible outcomes must equal:

```math
1
```

---

# 10. Probability Functions

Probability is defined for **events**.

The course represents the probability function as:

```math
Pr[\cdot]
```

and more formally:

```math
Pr[\cdot]:\mathcal P(\Omega)\rightarrow[0,1]
```

where:

```math
\mathcal P(\Omega)
```

is the **power set** of `\Omega`, meaning all possible subsets of the sample space.

Since events are subsets of the sample space:

> Give the probability function an event → receive its probability.

---

# 11. Random Variable

A **random variable** is a value determined by the outcome of a random experiment.

It usually converts a complicated outcome into a numerical property that is easier to analyze.

Example: flip two coins.

```math
\Omega = \{HH,HT,TH,TT\}
```

Define:

```math
X = \text{number of heads}
```

Then:

```text
HH → X = 2
HT → X = 1
TH → X = 1
TT → X = 0
```

Therefore:

```math
X \in \{0,1,2\}
```

### Main idea

> The outcome may be complicated, but the random variable extracts the property we care about.

---

# 12. Event vs. Random Variable

A **random variable** is a value that changes depending on the random outcome.

Example:

```math
X = \text{number of heads}
```

An **event** is a condition involving possible outcomes.

Example:

```math
X > 4
```

So:

```text
X     → random variable
X > 4 → event
```

This distinction is important for quiz questions.

---

# 13. Probability Distribution

A **probability distribution** describes how probability is distributed across the possible values of a random variable.

Example: flip two fair coins and define:

```math
X = \text{number of heads}
```

Then:

```math
Pr[X=0] = \frac14
```

```math
Pr[X=1] = \frac12
```

```math
Pr[X=2] = \frac14
```

This is the probability distribution of `X`.

---

# 14. Valid Probability Distribution

A valid discrete probability distribution must satisfy:

```math
0 \leq Pr[X=x] \leq 1
```

and:

```math
\sum_x Pr[X=x] = 1
```

A **normalizing constant** may be needed to make the probabilities sum to `1`.

---

# 15. Discrete vs. Continuous Random Variables

## Discrete

Possible values can be individually counted.

Examples:

- number of heads
- number of customers
- number of errors
- die roll
- number of emails

Example:

```math
X \in \{0,1,2,3,\ldots\}
```

## Continuous

Possible values lie across a continuous range.

Examples:

- height
- weight
- temperature
- time
- distance

Example:

```math
X \in \mathbb R
```

---

# 16. Probability Mass Function — PMF

A **probability mass function (PMF)** is used for **discrete** random variables.

It gives probabilities for exact values.

Example:

```math
Pr[X=3] = 0.2
```

For a discrete variable, it makes sense to ask:

> What is the probability that `X` equals exactly `3`?

### Memory

> PMF → discrete/countable values.

---

# 17. Probability Density Function

A **probability density function** is used for **continuous** random variables.

The height of the curve itself is **not** the probability.

Probability comes from the **area under the curve over an interval**.

Example:

```math
Pr[170 < X < 180]
```

is the area under the probability density function between `170` and `180`.

The total area under the curve must equal:

```math
1
```

For a continuous random variable:

```math
Pr[X=x] = 0
```

for one exact point.

We care about ranges instead.

---

# 18. Bernoulli Distribution

A **Bernoulli distribution** represents one trial with two possible outcomes.

Usually:

```text
success = 1
failure = 0
```

with:

```math
Pr[X=1] = p
```

and:

```math
Pr[X=0] = 1-p
```

Examples:

- Heads or Tails
- Pass or Fail
- Customer buys or does not buy
- Model prediction correct or incorrect

### Memory

> Bernoulli = one yes/no trial.

---

# 19. Binomial Distribution

A **Binomial distribution** counts how many successes occur across a fixed number of independent Bernoulli trials.

Notation:

```math
X \sim Binom(n,p)
```

where:

- `n` = number of trials
- `p` = probability of success on each trial

Example:

> Flip a coin 10 times. How many Heads occur?

### Relationship

```text
Bernoulli → one trial
Binomial  → many Bernoulli trials and count the successes
```

---

# 20. Geometric Distribution

A **Geometric distribution** models:

> How many attempts occur until the first success?

Example:

```text
T T T H
```

The first success occurs on trial:

```math
4
```

So:

```math
X=4
```

### Memory

> Geometric = how many attempts until first success?

---

# 21. Poisson Distribution

A **Poisson distribution** models the number of events occurring during an interval.

Examples:

- customers per hour
- website requests per second
- accidents per month
- occurrences of a word per page

The main parameter is:

```math
\lambda
```

which describes the expected event rate.

### Memory

> Poisson = HOW MANY events?

---

# 22. Exponential Distribution

An **Exponential distribution** models:

> How long until the next event?

Example:

If customers arrive randomly:

```text
Poisson     → customers per hour
Exponential → time until the next customer
```

A common form of the probability density function is:

```math
f(x)=\lambda e^{-\lambda x}
```

### Memory

> Exponential = waiting time until the next event.

---

# 23. Gaussian / Normal Distribution

The **Gaussian distribution**, also called the **Normal distribution**, is the classic bell-shaped distribution.

```text
               /\
             /    \
           /        \
__________/__________\__________
             μ
```

Values are concentrated near the mean.

Extreme values become increasingly uncommon.

Important parameters:

```math
\mu
```

= mean

and:

```math
\sigma^2
```

= variance

Notation:

```math
\mathcal N(\mu,\sigma^2)
```

---

# 24. Uniform Distribution

A **Uniform distribution** means the possible values are equally likely.

For a fair six-sided die:

```math
Pr[X=1]
=
Pr[X=2]
=
\cdots
=
Pr[X=6]
=
\frac16
```

Another important example:

If each of `n` elements can independently be included or excluded from a set, there are:

```math
2^n
```

possible subsets.

If all subsets are equally likely, the subsets are uniformly distributed.

| Distribution | Main Question |
|---|---|

| Binomial | How many successes in `n` trials? |

# 26. Las Vegas vs. Monte Carlo Algorithms

These are randomized **algorithm styles**, not probability distributions.

## Las Vegas Algorithm

The answer is guaranteed to be correct, but runtime can vary randomly.

```text
Correctness → guaranteed
Runtime     → uncertain
```

## Monte Carlo Algorithm

Runtime is controlled, but the result may be approximate or occasionally incorrect.

```text
Runtime     → controlled
Correctness → probabilistic
```

# 27. Why Probability Matters for Real Data

Probability is not only about coins and dice.

Real-world data contains uncertainty.

Even if an underlying process generates the data, individual observations can vary.

Two important sources of problems are:

- measurement error / noise
- process bias

---

# 28. Measurement Error / Noise

**Measurement error**, also called **noise**, is the difference between the true value and what we actually observe.

Examples:

- sensor error
- typos
- incorrect measurements
- missing information
- text failing to communicate sarcasm
- ambiguity
- slang

Observed data is often an imperfect version of the underlying reality.

---

# 29. Process Bias

**Process bias** occurs when the way we collect data does not represent the complete process we actually care about.

Example:

Suppose we want to understand:

> How humans communicate.

But all of the text comes from:

> Twitter / X.

The dataset may represent Twitter communication well but not all human communication.

Other examples:

- collecting only one language
- collecting only one age group
- collecting only one topic
- collecting only one geographic region

### Main idea

> A dataset can be correct but still unrepresentative.

---

# 30. Random Variables and Data

Suppose a dataset has features:

```math
X_1,X_2,\ldots,X_n
```

and a label:

```math
Y
```

Each feature can be treated as a random variable.

The label can also be treated as a random variable.

Each random variable has an underlying probability distribution.

Usually, those true distributions are unknown.

A major goal of statistics and machine learning is to learn about them from collected data.

---

# 31. Multivariate Distribution

A **multivariate distribution** involves multiple random variables together.

Example:

```math
X_1,X_2,X_3,Y
```

Instead of modeling every variable separately, we can model how the variables behave together.

This matters because variables may depend on each other.

---

# 32. Conditional Probability Distribution

A **conditional probability distribution** represents situations where one variable depends on information about another.

Notation:

```math
Pr[A|B]
```

Read:

> Probability of A given B.

The vertical bar separates:

```text
left side  → what we want to know
right side → information we already know
```

Example:

```math
Pr[\text{Positive Test}|\text{Disease}]
```

means:

> If the person actually has the disease, what is the probability the test is positive?

---

# 33. Conditioning and Logical Dependency

Conditioning asks:

> Once I know `B`, does my probability for `A` change?

For:

```math
Pr[A|B]
```

we act as if `B` is known and then ask about `A`.

This does not have to follow real-world time order.

Example:

```math
Pr[\text{Test Result}|\text{Disease}]
```

can model how disease affects a test result.

But we may observe the test result first and ask:

```math
Pr[\text{Disease}|\text{Test Result}]
```

That is reasoning backward from evidence.

This becomes important later with Bayes' Theorem.

---

# 34. Machine Learning Connection

Suppose:

```math
X_1,X_2,\ldots,X_n
```

are features, and:

```math
Y
```

is the label we want to predict.

A major machine-learning goal is understanding:

```math
Pr[Y|X_1,X_2,\ldots,X_n]
```

In English:

> Given these features, what is the probability of each possible label?

Example:

```text
Features
(word choice, sentence length, punctuation, context)
        ↓
Pr[Sentiment | Features]
        ↓
positive / neutral / negative
```

This is why conditional probability is fundamental to machine learning.

# 39. Representative Dataset

A dataset is **representative** when its sample distribution resembles the true data distribution.

```math

\text{data distribution}
```

More representative data generally gives a better picture of the underlying process.

# 40. `\delta`-Close

A function `f` is **`\delta`-close** to another function `g` if:

```math
\forall x,\; |f(x)-g(x)|\leq\delta
```

Meaning:

> For every possible input, the two functions differ by no more than `\delta`.

If:

```math
\delta=0
```

then:

```math
f=g
```

exactly.

Larger values of `\delta` allow larger differences.

---

# 41. `\delta`-Representative

The same idea can be extended to probability distributions.

If the sample distribution is sufficiently close to the data distribution, we can describe it as:

> `\delta`-representative.

Conceptually:

```math
\text{sample distribution}
\approx_\delta
\text{data distribution}
```

The problem is that we usually cannot directly calculate this because the true data distribution is unknown.

# 42. Limits

A **limit** describes what value something approaches.

Example:

```math
\lim_{x\to5}f(x)=10
```

means:

> As `x` gets closer and closer to `5`, `f(x)` gets closer and closer to `10`.

A limit describes approaching a value; it does not necessarily mean the variable literally reaches it.

Probability and statistics frequently use:


Meaning:

We do not literally collect infinite data.

It describes what happens as the sample becomes larger and larger.

# 44. `\epsilon`

# 45. Law of Large Numbers — LLN

## Main Idea

> As we collect more independent observations, the sample average tends to get closer to the true expected average.

Let:

```math
X_1,X_2,\ldots,X_n
```

be observations.

The sample mean is:

```math
\bar X_n
```

The true expected value is:

```math
\mu
```

The intuition is:

```math
\bar X_n\rightarrow\mu
```

as:

```math
n\rightarrow\infty
```

### Memory

> LLN = bigger sample → better estimate of the true average.

---

# 46. LLN Example — Coin Flips

For a fair coin:

```math
Pr[H]=0.5
```

With only four flips we might observe:

```text
H H H T
```

which is:

```math
75\%
```

Heads.

That does **not** mean the true probability of Heads is `75%`.

As more observations are collected, the observed percentage tends to move closer to the true probability.

Example:

```text
4 flips       → 75%
100 flips     → 54%
1,000 flips   → 51%
100,000 flips → 50.1%
```

---

# 47. Sample Mean vs. True Mean

Important notation:

```math
\bar X_n
```

= sample mean

Meaning:

> Average calculated from our collected data.

```math
\mu
```

= true / population mean

Meaning:

> The actual expected value of the underlying distribution.

Memory:

```text
X̄_n = our estimate
μ    = truth
```

---

# 48. i.i.d.

**i.i.d.** means:

> independent and identically distributed.

## Independent

One observation does not determine another.

Example:

One fair coin flip does not affect the next fair coin flip.

## Identically Distributed

Each observation comes from the same underlying distribution.

For repeated fair coin flips:

```math
Pr[H]=0.5
```

for every flip.

---

# 49. Gambler's Fallacy

The Law of Large Numbers does **not** mean future random outcomes must compensate for past outcomes.

Example:

If roulette lands Black many times in a row, Red does not suddenly become more likely on the next independent spin.

The next probability is unchanged.

What happens instead is that an early streak becomes a smaller fraction of the total as more observations are collected.

Example:

```text
13 extra Black results out of 26 spins   → huge effect
13 extra Black results out of 260 spins  → smaller effect
13 extra Black results out of 2,600      → tiny effect
```

The long-run percentage can approach the true probability without outcomes "paying back" the earlier streak.

---

# 50. Central Limit Theorem — CLT

## Main Idea

The Central Limit Theorem says:

> Given sufficiently large samples with enough independence, the distribution of the sample averages approaches a Gaussian / Normal distribution as the sample size increases.

The CLT is about the distribution of:

```math
\bar X_n
```

not necessarily the distribution of the original data.

### Memory

> CLT = bigger samples → averages form a bell-shaped sampling distribution.

---

# 51. Formal CLT Statement

If:

```math
X_1,X_2,\ldots
```

are independent and identically distributed with:

```math
E(X_i)=\mu
```

and:

```math
Var(X_i)=\sigma^2
```

with finite `\mu` and `\sigma`, then as:

```math
n\rightarrow\infty
```

the distribution of:

```math
\sqrt n(\bar X_n-\mu)
```

approaches:

```math
\mathcal N(0,\sigma^2)
```

Another useful intuition is:

```math
\bar X_n-\mu
```

behaves approximately like:

```math
\mathcal N
\left(
0,
\frac{\sigma^2}{n}
\right)
```

for sufficiently large `n`.

---

# 52. What the CLT Is NOT Saying

The CLT is **not** saying:

> The more times I calculate an average, the more Gaussian it becomes.

Instead:

> The more observations included inside each sample average, the distribution of those averages tends to become more Gaussian.

These are different:

```text
number of repetitions
vs.
sample size
```

This distinction is extremely important.

---

# 53. CLT Example

Suppose the original distribution is Uniform from `0` to `1`.

The original distribution is flat, not Gaussian.

## Sample size = 1

```text
Sample 1: [0.7] → mean 0.7
Sample 2: [0.2] → mean 0.2
Sample 3: [0.9] → mean 0.9
```

The sample means still resemble the Uniform distribution.

## Sample size = 2

```text
[0.2, 0.8] → 0.50
[0.1, 0.3] → 0.20
[0.9, 0.7] → 0.80
```

The means begin concentrating toward the center.

## Sample size = 10

Each mean combines 10 independent observations.

The distribution of sample means starts looking bell-shaped.

## Sample size = 100

Each mean combines 100 observations.

The sample means become tightly concentrated around:

```math
\mu=0.5
```

and their distribution looks approximately Gaussian.

# 54. CLT: Repetitions vs. Sample Size

Suppose code uses:

```python
size=(100000, sample_size)
```

There are two separate quantities.

## `100000`

The number of separate samples / experiments.

Think:

```text
100,000 rows
```

This provides many sample means so the histogram is smooth.

Increasing this mostly improves the **picture** of the sampling distribution.

## `sample_size`

The number of observations inside each sample.

Think:

```text
columns per row
```

This is the important:

```math
n
```

in the CLT.

Increasing `sample_size` changes the actual distribution of sample means.

# 55. LLN vs. CLT

| Concept | Main Question | Result |
|---|---|---|
| Law of Large Numbers | Does my sample mean become accurate? | `\bar X_n` approaches `\mu` |
| Central Limit Theorem | What does the distribution of sample means look like? | It approaches a Gaussian |

Easy memory:

> **LLN = bigger sample → better average**

> **CLT = bigger samples → averages form a bell curve**

---

# 56. Why Larger Samples Give Better Means

The spread of a sample mean decreases as the sample size grows.

Its standard deviation is approximately:

```math
\frac{\sigma}{\sqrt n}
```

So increasing:

```math
n
```

makes the sample mean less variable.

A mean based on many independent observations is generally more stable than one based on only a few observations.

Even if you calculate a two-observation average 100,000 times, every individual two-observation average is still noisy.

The 100,000 repetitions only show that noisy sampling distribution very clearly.

---

# 57. CLT Limitations

The CLT does not mean every dataset instantly becomes Normal.

Important limitations:

## Convergence is not instant

There is no universal sample size where:

> "Now it is Normal."

The required sample size depends on the original distribution.

## Tails converge more slowly

The center may look Normal before the extreme tails do.

## Skew matters

Strongly skewed original distributions may require much larger samples.

## Independence matters

The simplest CLT assumes i.i.d. random variables.

There are CLT versions that allow certain dependencies, but their assumptions differ.

### Main warning

> Do not blindly assume 100 or 1,000 observations automatically makes everything perfectly Normal.

---

# 58. Real-World CLT Examples

## Test Scores

A total test score combines results from many questions.

Each question contributes to the final score.

With many questions, the distribution of total or average scores can often look approximately Normal.

## Human Growth

Many small growth-related effects accumulate over time.

Adding many small contributions can produce approximately Normal-looking measurements.

This helps explain why Gaussian distributions appear frequently in real data.

# 67. Quiz / Practice Concepts Worth Remembering

## Uniform random choices

If one person independently chooses one number from `1–10`, the probability that another independent uniform choice matches it is:

```math
\frac1{10}
```

The first person can choose anything.

The second person has exactly one matching option out of ten.

---

## Random subsets

If each of `n` elements is independently included or excluded:

```math
2^n
```

possible subsets exist.

If every element is included using a fair coin, all subsets are equally likely.

If instead we ask:

> How many elements were included?

the count follows:

```math
Binom\left(n,\frac12\right)
```

---

## Probability Distribution Validity

For a valid discrete probability distribution:

```math
0\leq f(x)\leq1
```

and:

```math
\sum_x f(x)=1
```

Both conditions matter.

---

## Independent Trials

Past independent outcomes do not change the probability of the next outcome.

Example:

After rolling a six four times:

```math
Pr[\text{next roll is 6}]
=
\frac16
```

The previous rolls do not alter the next independent die roll.

---

## Events vs. Random Variables

A quantity such as:

> Number of pivots used by randomized Quicksort

is a **random variable**.

A statement such as:

> The treatment group's mean difference is greater than the control group's mean difference

describes a condition/set of outcomes and is treated as an **event**.

# 69. What to Memorize

1. **Sample space `\Omega`** = all possible outcomes.
2. **Outcome** = one actual result.
3. **Event** = a set/condition of outcomes.
4. **Probability** = likelihood of an event.
5. **Random variable** = value determined by a random outcome.
6. **Probability distribution** = describes probabilities of random-variable values.
7. **PMF** = discrete random variables.
8. **Probability density function** = continuous random variables; probability is area under the curve.
9. **Bernoulli** = one success/failure trial.
10. **Binomial** = number of successes in a fixed number of trials.
11. **Geometric** = attempts until the first success.
12. **Poisson** = number of events in an interval.
13. **Exponential** = time until the next event.
14. **Gaussian / Normal** = bell-shaped distribution.
15. **Uniform** = values/outcomes are equally likely.
16. **Measurement noise** = error in observations.
17. **Process bias** = collected data does not represent the full process well.
18. **Conditional probability `Pr[A|B]`** = probability of `A` once `B` is known.
19. **Data distribution** = true hidden real-world distribution.
20. **Sample distribution** = distribution estimated from collected data.
21. **Representative data** = sample distribution resembles the data distribution.
22. **i.i.d.** = independent and identically distributed.
23. **LLN** = larger sample → sample average approaches true average.
24. **CLT** = averages of increasingly large samples → approximately Gaussian sampling distribution.
25. **CLT is driven by sample size `n`, not by simply doing more repetitions.**
26. More repetitions mostly make the histogram of the sampling distribution clearer.

# 70. One-Paragraph Week 1 Summary

Week 1 introduces probability as a mathematical way to describe uncertain real-world processes. A random process has a sample space `\Omega` containing all possible outcomes, while an event is a set or condition involving those outcomes. Random variables turn properties of outcomes into values that can be analyzed, and probability distributions describe how likely those values are. Discrete random variables use PMFs, while continuous random variables use probability density functions where probability comes from area over an interval. Common distributions include Bernoulli, Binomial, Geometric, Poisson, Exponential, Uniform, and Gaussian. Real datasets contain uncertainty from noise and process bias, so features and labels can be treated as random variables generated by an underlying data distribution. Because we only observe a finite dataset, we estimate a sample distribution and hope it is representative of the true process. Finally, the Law of Large Numbers explains why larger samples produce more reliable averages, while the Central Limit Theorem explains why the distribution of sample averages becomes approximately Gaussian as the number of observations inside each sample increases.

# 1.1 Conditional Distributions

## Main idea

A **conditional distribution** tells you:

> **How does one variable behave after I learn something about another variable?**

Example:

\[
Pr[X=x \mid B]
\]

means:

> What is the probability that \(X=x\), **given that \(B\) is already known to be true**?

### Important notation

- \(X\) = random variable
- \(x\) = one specific value that \(X\) can take
- \(X=x\) = the event that \(X\) took that specific value
- \(A \cap B\) = \(A\) **AND** \(B\)

The formula:

\[
Pr[A\mid B]
=
\frac{Pr[A\cap B]}{Pr[B]}
\]

For a random variable:

\[
Pr[X=x\mid B]
=
\frac{Pr[(X=x)\cap B]}{Pr[B]}
\]

## ELI5

Suppose we have mangoes with:

- yellowness
- softness

If I ask:

> "What does yellowness look like overall?"

I use the full distribution.

If I instead tell you:

> "This mango has softness = 1."

then I ask:

> "Among mangoes with softness = 1, what does yellowness look like?"

That means:

1. Keep only cases where softness = 1.
2. Remove the others **for this question only**.
3. Rescale the remaining probabilities so they add to 1 again.

### Memory trick

> **Conditional = filter, then renormalize.**

## Why this matters

This is the probability version of:

> **New information changes what I expect.**

Machine learning often asks questions like:

\[
Pr[\text{spam}\mid\text{email features}]
\]

or

\[
Pr[\text{disease}\mid\text{symptoms}]
\]

# 1.2 Marginal Distributions

## Main idea

A **marginal distribution** tells you:

> **What does one variable look like by itself if I ignore the other variables?**

If you have a joint distribution of \(X\) and \(Y\), but only care about \(X\):

\[
p(x)=\sum_y p(x,y)
\]

## ELI5

Suppose yellowness = 3 appears with several different softness values.

If you only care about yellowness, add all those probabilities together.

Example:

\[
P(X=3,Y=2)=0.20
\]

\[
P(X=3,Y=3)=0.10
\]

\[
P(X=3,Y=4)=0.10
\]

Then:

\[
P(X=3)=0.20+0.10+0.10=0.40
\]

You are **not filtering** anything out.

You are combining all ways \(X=3\) can happen.

### Memory trick

> **Marginal = ignore another variable by summing over it.**

## Conditional vs. Marginal

### Conditional

\[
P(X\mid Y=1)
\]

> "I care about \(Y\), and I know \(Y=1\)."

**Filter.**

### Marginal

\[
P(X)
\]

> "I do not care what \(Y\) is."

**Combine.**

# 1.3 Independence

## Main idea

Independence asks:

> **If I learn the value of one variable, does that change what I expect about the other?**

If not, they are independent.

The formal definition is:

\[
Pr[(X=x)\cap(Y=y)]
=
Pr[X=x]Pr[Y=y]
\]

for all \(x\) and \(y\).

But the easiest interpretation is:

\[
Pr[X=x\mid Y=y]
=
Pr[X=x]
\]

Meaning:

> Learning \(Y=y\) gave me no new information about \(X\).

## ELI5

Two separate fair coin flips are independent.

Knowing:

> Flip 2 = heads

does not change:

\[
Pr[\text{Flip 1 = heads}]=0.5
\]

## Dependent variables

If learning \(Y\) changes what you expect about \(X\), they are dependent.

Example:

- \(X\) = temperature
- \(Y\) = ice cream sales

Knowing the temperature may change what you expect about ice cream sales.

## Important warnings

### Dependence does not mean causation

Two variables can be dependent because of a third variable.

Example:

- hot weather
- ice cream sales
- swimming

Ice cream sales and swimming may be related because both are affected by temperature.

### Dependence is not transitive

If:

- \(X\) depends on \(Z\)
- \(Z\) depends on \(Y\)

that does **not** guarantee that \(X\) depends on \(Y\).

### Independence notation

\[
X \perp Y
\]

means:

> \(X\) and \(Y\) are independent.

# 2.1 Conditional Distributions and Causality

## Main idea

Conditional probability can be used in two directions:

### Forward

Cause → effect

Example:

\[
Pr[\text{message}\mid\text{cat scratching}]
\]

> If the cat scratches the couch, how likely is a message?

### Backward

Observed effect → possible cause

Example:

\[
Pr[\text{cat scratching}\mid\text{message}]
\]

> I got a message. How likely is it that the cat was scratching?

## Important idea

These are **not the same probability**.

Also, conditioning does **not automatically prove real-world causation**.

It is better to think:

> The thing on the right of \(\mid\) is what I already know.

## Bayesian networks

A dependency graph can show relationships among random variables.

Example:

```text
Henri Scratching
       ↓
Couch Ripping Sound
       ↓
Wife Message
```

Each node is a random variable.

Each arrow shows a dependency / chosen conditioning direction.

## Why this lesson matters

It prepares you for Bayes' theorem:

> We often know how causes produce evidence, but we want to reason backward from evidence to a possible cause.

---

# 2.2 Bayes' Theorem

## Main idea

Bayes' theorem lets you reverse a conditional probability.

\[
\boxed{
Pr[A\mid B]
=
\frac{Pr[B\mid A]Pr[A]}{Pr[B]}
}
\]

## Why it works

Both directions refer to the same joint probability:

\[
Pr[A\cap B]
=
Pr[A\mid B]Pr[B]
\]

and:

\[
Pr[A\cap B]
=
Pr[B\mid A]Pr[A]
\]

Therefore:

\[
Pr[A\mid B]Pr[B]
=
Pr[B\mid A]Pr[A]
\]

which gives Bayes' theorem.

## ELI5

Suppose:

- \(D\) = disease
- \(+\) = positive test

You may know:

\[
Pr[+\mid D]
\]

> If someone has the disease, how likely is a positive test?

But what you actually want is:

\[
Pr[D\mid +]
\]

> If someone tested positive, how likely is the disease?

You cannot simply flip the condition.

Bayes fixes the direction.

## Four important terms

\[
p(x\mid y)
=
\frac{p(y\mid x)p(x)}{p(y)}
\]

### Prior

\[
p(x)
\]

What you believed **before** seeing new evidence.

### Likelihood

\[
p(y\mid x)
\]

How likely the evidence is if \(x\) is true.

### Evidence

\[
p(y)
\]

How common the observed evidence is overall.

### Posterior

\[
p(x\mid y)
\]

Your updated belief **after** seeing the evidence.

### Memory trick

> **Prior + evidence → posterior**

or:

> **old belief + new information → updated belief**

# 3.1 Covariance and Correlation

## Main idea

Now that we know variables can be dependent, we want a number that summarizes how they move together.

---

## Covariance

\[
\boxed{
Cov(X,Y)
=
E[(X-E[X])(Y-E[Y])]
}
\]

ELI5:

- Is \(X\) above or below its average?
- Is \(Y\) above or below its average?
- Do they tend to move in the same direction?

### Interpretation

\[
Cov(X,Y)>0
\]

They tend to move in the same direction.

\[
Cov(X,Y)<0
\]

They tend to move in opposite directions.

\[
Cov(X,Y)=0
\]

No linear co-movement is detected.

## Correlation

Pearson's correlation coefficient is:

\[
\boxed{
\rho_{X,Y}
=
\frac{Cov(X,Y)}
{\sigma(X)\sigma(Y)}
}
\]

Correlation is basically:

> **standardized covariance**

Its useful range is:

\[
-1\le\rho\le1
\]

### Interpretation

- \(\rho=1\): perfect positive linear relationship
- near \(1\): strong positive linear relationship
- \(\rho=0\): no linear relationship
- near \(-1\): strong negative linear relationship
- \(\rho=-1\): perfect negative linear relationship

## Important: slope is not correlation

A perfect line with positive slope has correlation \(+1\), whether the slope is:

\[
0.1,\;1,\;100
\]

Correlation measures how perfectly two variables linearly track each other, not how steep the line is.

## The BIG trap

\[
X,Y\text{ independent}
\Rightarrow
Cov(X,Y)=0
\Rightarrow
\rho_{X,Y}=0
\]

But:

\[
\boxed{
\rho_{X,Y}=0
\not\Rightarrow
X,Y\text{ independent}
}
\]

Why?

Because Pearson correlation measures **linear** relationships.

A strong curved relationship can still have correlation 0.

## Useful alternate covariance form

\[
\boxed{
Cov(X,Y)
=
E[XY]-E[X]E[Y]
}
\]

For independent variables:

\[
E[XY]=E[X]E[Y]
\]

so:

\[
Cov(X,Y)=0
\]

# 3.2 Linear Regression

## Main idea

This is where Week 3 starts turning statistics into an actual ML model.

> **Given input variables, can we predict a continuous output using the best-fitting linear model?**

Examples:

- house size → price
- study time → exam score
- mango features → flavor rating

---

## Regression

Regression predicts a **continuous numerical output**.

Example:

\[
72.5,\quad 500000,\quad 3.8
\]

---

## Linear Regression

With one input variable:

\[
\boxed{
f(x^{(i)};\theta_1,\theta_2)
=
\theta_1x^{(i)}+\theta_2
}
\]

where:

- \(\theta_1\) = slope
- \(\theta_2\) = intercept / offset

Training means finding the best values of those parameters.

With multiple features:

\[
f(x)
=
\theta_1x_1+\theta_2x_2+\cdots+\theta_nx_n+\theta_{n+1}
\]

Each feature gets its own coefficient.

---

## Least Squares Regression

Least squares tells us **how to judge which line is best**.

For every sample:

\[
\text{error}
=
\text{prediction}-\text{ground truth}
\]

Then square it:

\[
(\text{prediction}-\text{ground truth})^2
\]

Then add all squared errors:

\[
\boxed{
L
=
\sum_{i=1}^{m}
\left(
f(x^{(i)};\theta)-y_{gt}^{(i)}
\right)^2
}
\]

The model chooses parameters that make:

\[
L
\]

as small as possible.

### Why square?

Without squaring:

\[
-2+2=0
\]

and two mistakes could cancel.

Squaring gives:

\[
(-2)^2+(2)^2=8
\]

Also, large errors get punished more heavily.

---

## Loss function

A **loss function** is simply:

> A scoring system that measures how wrong the model is.

For least squares:

> smaller loss = better model

---

## Connection to covariance

For one input feature, the optimal slope becomes:

\[
\boxed{
\theta_1^*
=
\frac{Cov(x,y_{gt})}{V[x]}
}
\]

This connects directly to Lesson 3.1.

Interpretation:

> The slope depends on how much \(x\) and the target \(y_{gt}\) vary together, relative to how much \(x\) varies on its own.

So:

> **Correlation/covariance describe relationships. Regression uses those relationships for prediction.**

---

## Linear models cannot learn every shape

If the true function is:

\[
y(x)=x+2+0.1\sin(10x)
\]

a linear model cannot reproduce all the little waves.

It can only find the best straight-line approximation, roughly:

\[
y=x+2
\]

### Important ML idea

> A model can only learn patterns that its model structure can represent.

---

## Multiple input features

Example:

\[
\text{house price}
=
\theta_1(\text{size})
+
\theta_2(\text{bedrooms})
+
\theta_3(\text{age})
+
\theta_4
\]

One complication:

> Input variables may themselves be related.

Example:

- bigger houses often have more bedrooms

So the model needs to separate each feature's individual contribution.

---

## Predicted vs. Actual Plot

For multi-input regression, a useful graph is:

- x-axis = predicted value
- y-axis = actual value

Perfect predictions lie on:

\[
y=x
\]

Points near the line = good predictions.

Points far from the line = larger errors.

The vertical difference between prediction and actual is the **residual**.

# Week 3 — Most Important Comparisons

## Marginal vs. Conditional

**Marginal**

> Ignore another variable.

\[
P(X)
\]

**Conditional**

> Restrict based on another variable.

\[
P(X\mid Y=y)
\]

Memory:

> **Marginal = combine. Conditional = filter.**

---

## Independence vs. Dependence

**Independent**

\[
P(X\mid Y)=P(X)
\]

Learning \(Y\) changes nothing about \(X\).

**Dependent**

Learning \(Y\) changes what you expect about \(X\).

---

## Covariance vs. Correlation

**Covariance**

Raw measure of joint movement.

**Correlation**

Standardized covariance, easier to compare and interpret.

---

## Correlation vs. Regression

**Correlation**

> How strongly do \(X\) and \(Y\) move together linearly?

**Regression**

> Can I use \(X\) to predict \(Y\)?

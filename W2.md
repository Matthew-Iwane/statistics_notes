# 1.1 — What Are Statistics?

## Statistics

A **statistic** is a function computed from a sample of data that we use to estimate the same function applied to the whole population.

### Main idea

- **Population** = everything we care about.
- **Sample** = smaller subset we actually observe.
- **Statistic** = a value calculated from the sample.
- We hope the statistic tells us something useful about the population or future data.

## Descriptive Statistics

Descriptive statistics help answer:

- What is normal or typical?
- Where is the center of the data?
- How spread out is the data?
- Are there unusual values or outliers?

Examples include mean, median, variance, standard deviation, quantiles, minimum, and maximum.

## Dataset Notation

For a dataset \(X\):

\[
X_0, X_1, X_2, \ldots, X_{n-1}
\]

The course uses Python-style indexing, so indexing starts at 0.

If \(X\) is a matrix:

\[
X_{i,j}
\]

means row \(i\), column \(j\).

### ML interpretation

- **row** = one observation / record
- **column** = one feature / variable

# 1.2 — Mean, Variance, Standard Deviation, Quantiles, and Skewness

## Mean

\[
\bar{x}:=\frac{1}{n}\sum_{i=1}^{n}x_i
\]

**ELI5:** add all values and divide by how many values there are.

The mean tells you roughly where the data is centered.

## Expected Value

For a random variable \(X\), the mean is called the **expected value**:

\[
E[X]
\]

For a discrete random variable:

\[
E[X]:=\sum_{x\in X}Pr[X=x]x
\]

Important notation:

- \(X\) = random variable
- \(x\) = one possible value of \(X\)
- \(Pr[X=x]\) = probability that \(X\) takes value \(x\)
- \(E[X]\) = expected value / mean of \(X\)

**ELI5:** expected value is a probability-weighted average.

## Variance

Variance measures how spread out values are around the mean.

The lesson uses:

\[
V[X]
\]

One form is:

\[
V[X]:=\frac{1}{n}\sum_{x\in X}(x-E[X])^2
\]

**ELI5:**

1. Find the mean.
2. Find each value's distance from the mean.
3. Square those distances.
4. Average them.

Large variance = more spread out.  
Small variance = more tightly grouped.

Another useful form:

\[
V[X]=E[X^2]-(E[X])^2
\]

Remember:

- \(E[X^2]\) = square first, then take expected value
- \((E[X])^2\) = take expected value first, then square

## Population vs Sample Variance

The lesson distinguishes:

\[
\frac{1}{n}
\]

from:

\[
\frac{1}{n-1}
\]

The sample-variance form uses \(n-1\).

## Standard Deviation

\[
SD(X)=\sqrt{V[X]}
\]

**ELI5:** standard deviation is the square root of variance and expresses spread in the original units.

# Quantiles

A **quantile** is a cutoff point in sorted data.

For fraction \(p\) between 0 and 1, the \(p\)-quantile is the value \(x\) such that at most fraction \(p\) of \(X\) is below \(x\), and at most fraction \(1-p\) is above \(x\).

Main values:

\[
0.0\text{-quantile}=\text{minimum}
\]

\[
0.5\text{-quantile}=\text{median}
\]

\[
1.0\text{-quantile}=\text{maximum}
\]

## Percentiles

The \(k\)th percentile is:

\[
\left(\frac{k}{100}\right)\text{-quantile}
\]

Examples:

- 50th percentile = median
- 90th percentile = cutoff with about 90% below it
- top 1% = roughly 99th percentile and above

## Deciles

The \(k\)th decile is:

\[
\left(\frac{k}{10}\right)\text{-quantile}
\]

Example:

\[
\text{3rd decile}=0.3\text{-quantile}=30\text{th percentile}
\]

## Quantiles in the Simulation Graphs

The course plots the 10th, 30th, 50th, 70th, and 90th percentiles of cumulative averages across simulations.

Main point:

\[
\text{more trials} \rightarrow \text{less spread between quantiles}
\]

For coin flips, the curves move toward \(0.5\).  
For the shopping example, they move toward \(0.1\).

The range from the 10th to 90th percentile contains the middle:

\[
90\%-10\%=80\%
\]

of simulations.

---

# Skewness

The lesson uses:

\[
\text{skew}(X)=
E\left[\left(\frac{X-E[X]}{SD(X)}\right)^3\right]
\]

Main idea: skewness tells you which direction the distribution's tail stretches.

- \(	ext{skew}(X)\approx 0\): roughly symmetric
- \(	ext{skew}(X)>0\): right-skewed
- \(	ext{skew}(X)<0\): left-skewed

# 2.1 — Resampling Data and Bias

## Dataset Bias

A dataset is a sample of a population, but it is usually not a perfectly random or unbiased sample.

Main point:

\[
\boxed{\text{real datasets are usually biased in some way}}
\]

## Sampling With Replacement

A selected point can be selected again.

Example:

```text
Original: [A, B, C, D]
Possible sample: [A, C, C, B]
```

Duplicates are allowed.

## Sampling Without Replacement

Once a point is selected, it cannot be selected again.

Example:

```text
Original: [A, B, C, D]
Possible sample: [C, A, D, B]
```

No duplicates.

# Bootstrapping

Given a dataset containing \(n\) samples:

1. Sample \(n\) data points **with replacement**.
2. Compute the statistic of interest.
3. Save that statistic.
4. Repeat many times.
5. Analyze the distribution of those statistics.

The lesson says 1,000 to 10,000 bootstrap samples are common.

Example:

\[
n=10,000
\]

Each bootstrap sample also contains 10,000 draws with replacement.

If repeated 5,000 times, you get 5,000 bootstrap statistics.

## What Do You Do With the Bootstrap Output?

Suppose the statistic is the mean. The repeated means form a **distribution of bootstrap means**.

The main question is:

> How much does the statistic move around across different bootstrap samples?

You can examine variance, standard deviation, quantiles, and confidence intervals.

# Bootstrap Confidence Interval Intuition

A 95% bootstrap interval can be formed using the:

\[
2.5\%\text{ quantile}
\]

and

\[
97.5\%\text{ quantile}
\]

because:

\[
2.5\%+95\%+2.5\%=100\%
\]

So the interval contains the **middle 95%** of bootstrap estimates.

## Drug Example

The lesson uses:

```python
scores = [-3.6, -3.3, -1.8, 1.1, 1.6, 1.7, 2.9, 3.5]
```

Positive = patients felt better.  
Negative = patients felt worse.

If the 95% interval contains:

\[
\mu=0
\]

the lesson says we cannot rule out no average effect.

# 2.2 — Holdout Testing and Cross Validation

## Main Problem

A model can memorize its training data.

So:

\[
\boxed{\text{do not train and test on the same data}}
\]

# Training Set

The model learns directly from the training set.

Think: **study material**.

# Validation Set

The validation set helps compare or tune models.

Think: **practice quiz**.

You can train multiple models on the same training data and compare them on the validation set.

If you repeatedly tune to the same validation set, you can eventually overfit to the validation set too.

# Testing Set

The testing set is the final untouched evaluation.

Think: **final exam**.

Once you evaluate the final model on the testing set, you should not modify the model based on that result.

# Training / Validation / Testing Mental Model

\[
\boxed{\text{Training}=\text{learn}}
\]

\[
\boxed{\text{Validation}=\text{compare/tune}}
\]

\[
\boxed{\text{Testing}=\text{final evaluation}}
\]

# Holdout Testing

Holdout testing means splitting the dataset once.

Example:

```text
100 total points
90 → training
10 → testing
```

The train and test sets must not overlap.

Their distributions should also roughly match the original data distribution.

# Why One Split Can Be Bad

One random split may be lucky or unlucky.

This motivates cross validation.

# Cross Validation

Cross validation evaluates the model across multiple train/test arrangements.

Main idea:

\[
\boxed{\text{do not trust only one split}}
\]

# Fold

A **fold** is one particular train/test arrangement in cross validation.

Think: **one round of evaluation**.

# k-Fold Cross Validation

Split the dataset into \(k\) chunks. Each chunk gets one turn as the testing set.

Example: 5-fold cross validation

```text
Chunks: A B C D E

Fold 1: Test A | Train B C D E
Fold 2: Test B | Train A C D E
Fold 3: Test C | Train A B D E
Fold 4: Test D | Train A B C E
Fold 5: Test E | Train A B C D
```

Now every chunk has been testing data once.

# Holdout vs Cross Validation vs Fold

| Term | Meaning |
|---|---|
| Training set | data used to learn |
| Validation set | data used to compare/tune |
| Testing set | final untouched evaluation data |
| Holdout testing | one train/test split |
| Cross validation | repeated evaluation using multiple splits |
| Fold | one train/test arrangement |

# Random Cross Validation

Randomly generate different train/test folds.

Exact duplicate test sets are rejected, but folds may still overlap heavily.

# Stratified Cross Validation

Split the dataset into \(k\) chunks while trying to preserve the label distribution.

Each chunk becomes the testing set once.

# Leave One Out Cross Validation

If there are \(n\) data points and you use \(n\) folds, each fold has one testing point.

Example:

```text
100 data points
100 folds

Each fold:
99 training points
1 testing point
```

This is called **Leave One Out Cross Validation**.
